ArcMFA-Net-Reproducibility

Reproducibility package for low-voltage AC series arc fault detection based on Arc-IET-WVD and ArcMFA-Net.

Research Materials

1. Original current data and dataset manifest.
2. Feature extraction scripts and preprocessing parameters.
3. ArcMFA-Net model implementation and trained weights.
4. Complete dataset containing 20,000 feature images.

All research data packages are password-protected.
